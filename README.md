**Clint Yeastwood Rises** — one original dad joke for make.fun's [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty, $5 in USDC. A sourdough starter gets a very serious name, and every morning it lives up to it: the pun lands on the last three words. The program in `main.ts` validates the joke against the gate (UTF-8 text, 1–200 characters, not only white space) and writes it to `entry.txt` in the output directory — nothing else, no network, fully deterministic.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
